# Myntra Review Scraper

## Project Summary

Myntra Review Scraper is a Python-based web scraping application designed to collect product reviews and ratings from Myntra. It helps users extract customer feedback and perform basic review analysis to understand customer opinions and product experiences.

## Technologies Used
- Python
- Selenium
- BeautifulSoup
- Streamlit
- Flask
- MongoDB
- Pandas

## Features
- Extract product reviews and ratings.
- Collect customer feedback.
- Store scraped data.
- Analyze product reviews.
